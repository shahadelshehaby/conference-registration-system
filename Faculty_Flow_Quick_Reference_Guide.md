# Faculty Member CRS Flow - Quick Reference Guide
## University of Dubai Conference Registration System

## Quick Navigation by Phase

### 🔐 PHASE 1: AUTHENTICATION & PROFILE SETUP
**Duration:** Immediate (< 5 minutes)

| Action | Details | Outcome |
|--------|---------|---------|
| Navigate to CRS | Visit UD CRS portal | Redirected to SSO login |
| SSO Login | Enter UD Microsoft 365 credentials | Profile auto-populated from AD |
| Confirm Profile | Review auto-filled data (name, ID, college, rank, email) | Access to dashboard granted |

**Key Point:** No separate registration needed; one-time profile confirmation.

### 📝 PHASE 2: APPLICATION CREATION & SUBMISSION
**Duration:** 30-60 minutes per application | Draft retention: 90 days

| Section | What to Fill | Required | Validation |
|---------|--------------|----------|-----------|
| **A. Applicant Info** | Auto-filled (name, ID, college, rank, email) | N/A | Read-only |
| **B. Conference Details** | Conference name, URL, location, dates, type | ✅ All required | Dates must be future; URL must be valid |
| **C. Paper Details** | Paper/presentation title | ✅ Required | Max 300 characters |
| **D. ELIGIBILITY** ⚠️ | 4 Yes/No questions (probation, first conference, "UD" in paper, SCOPUS-indexed) | ✅ **ALL MUST BE YES** | If any No → Cannot submit, error message shows reason |
| **E. Documents** | Acceptance letter (req'd), paper draft (req'd), registration form (opt), agenda (opt), visa (cond) | ✅ Required docs | Max 10 MB per file; all scanned for malware |
| **F. Financial Estimate** | Registration fee, flights, accommodation, per diems (all in AED) | ✅ All required | Auto-calculates accommodation total & grand total; auto-fills if quotations attached |
| **G. Substitution & Leave** | Substitution plan, leave dates, substitute faculty name | ✅ All required | Leave end date ≥ start date; substitute from same college |

**Before Submitting:**
- [ ] All required fields filled
- [ ] Section D is all "YES"
- [ ] All required documents uploaded
- [ ] Financial estimate complete
- [ ] Substitution plan confirmed

**Upon Submission:**
- ✅ Application reference generated: **CRS-[YEAR]-[COLLEGE]-[#]**
- ✅ Status changes to: **Pending Dean** (or **Pending RC** if delegated)
- ✅ Faculty receives confirmation email with reference number
- ✅ Application routed to first approver

**If Validation Fails:**
- ❌ Error message displayed
- ❌ Faculty fixes issues and resubmits
- ❌ No reference # generated until successful submission

### ✅ PHASE 3: APPLICATION APPROVAL WORKFLOW
**Duration:** 7–10 working days (target) | **Up to 15 working days** if returns/revisions needed

#### **Stage 1: College Dean Review**
| Item | Detail |
|------|--------|
| **SLA** | 2 working days |
| **Approver** | Your College Dean (CEIT, Business, or Law) |
| **Possible Outcomes** | ✅ Approved → Stage 2 \| ❌ Rejected → End \| 🔄 Returned → Revise & resubmit \| ❓ Info requested → Answer thread \| 📋 Delegated to RC → Stage 1A (advisory) |
| **Faculty Sees** | Status: "Pending Dean" + Approver name + Days remaining |
| **If Escalated** | At 50% SLA (1 day): Reminder email to Dean. At 100% SLA (2 days): Urgent flag + second reminder |
| **Faculty Action If Returned** | Review Dean's feedback, edit form sections, resubmit within 14 days |

#### **Stage 1A: Research Committee Advisory (Optional)**
*Only if Dean delegated at Stage 1*

| Item | Detail |
|------|--------|
| **SLA** | 2 working days |
| **Approver** | College Research Committee (5–7 faculty) |
| **Role** | Advisory only – no approval/rejection authority |
| **Outcome** | Feedback & recommendations → Sent back to Dean |
| **Faculty Sees** | Status: "Pending RC" + Comments from committee members |
| **Faculty Action** | Read feedback; Dean will make final decision next |

#### **Stage 1B: Dean Review (Post-RC)**
*Only if RC advisory completed*

| Item | Detail |
|------|--------|
| **SLA** | 2 working days (fresh clock) |
| **Approver** | Same College Dean |
| **Task** | Review RC feedback and make final decision |
| **Possible Outcomes** | ✅ Approved → Stage 2 \| ❌ Rejected → End \| 🔄 Escalate to Director → Director reviews |
| **Faculty Sees** | Status: "Pending Dean (Post-RC)" |

#### **Stage 2: Director of Research Review**
| Item | Detail |
|------|--------|
| **SLA** | 2 working days |
| **Approver** | Director of Research (university-wide) |
| **Focus** | SCOPUS compliance, research merit |
| **Possible Outcomes** | ✅ Approved → Stage 3 \| ❌ Rejected → End \| 🔄 Returned → Revise & resubmit |
| **Faculty Sees** | Status: "Pending Director" + Days remaining |

#### **Stage 3: VP of Academic Affairs Review**
| Item | Detail |
|------|--------|
| **SLA** | 1 working day |
| **Approver** | VP of Academic Affairs |
| **Focus** | Cross-college alignment, workload impact |
| **Possible Outcomes** | ✅ Approved → Stage 4 \| ❌ Rejected → End |
| **Faculty Sees** | Status: "Pending VP" |

#### **Stage 4: UD President – Final Approval**
| Item | Detail |
|------|--------|
| **SLA** | 1 working day |
| **Approver** | UD President |
| **Authority** | Binding, irreversible |
| **Signature** | DocuSign/Adobe Sign (digital signature captured) |
| **Possible Outcomes** | ✅ **FINAL APPROVE** → Application approved + PRF generation triggered \| ❌ **FINAL REJECT** → End |
| **Faculty Sees** | Status: "Approved" + Approval letter available for download |
| **Faculty Receives** | Email: "Congratulations! Your application is approved." + PDF approval letter + PRF notification |

### Application Status Badges Throughout

| Status | Meaning | What You Can Do |
|--------|---------|-----------------|
| 📋 **Draft** | Not yet submitted | Edit, save, delete, continue later |
| ⏳ **Pending [Stage]** | Awaiting approver decision | View, check comments, track progress |
| 🔄 **Returned** | Sent back for revision | Edit form, resubmit within 14 days |
| ✅ **Approved** | President approved | Download approval letter, review PRF |
| ❌ **Rejected** | Rejected at any stage | View rejection reason, optionally resubmit next year |

### Key Dashboard Features During Approval
- **Timeline View:** Visual progress bar showing completed, current, and remaining stages
- **SLA Indicator:** Green (on time) | Amber (50–100% elapsed) | Red (overdue)
- **Approver Comments:** View written feedback, notes, questions
- **Stage Duration:** How long each approver took
- **Next Deadline:** When next stage must be completed

### 💰 PHASE 4: PRF AUTO-GENERATION & REVIEW
**Duration:** 3–5 days for faculty review | 8–10 working days for full PRF approval chain

#### **PRF Auto-Generation (Automatic upon President Approval)**

| Item | Detail |
|------|--------|
| **Trigger** | President clicks "Final Approve" on your application |
| **Timing** | Immediate (within seconds) |
| **What Happens** | PRF created and pre-filled with your application data |
| **You Receive** | Email: "Your PRF is Ready for Review" with deep-link to CRS |
| **PRF Status** | "Draft – Faculty Review" (you can still edit) |
| **Deadline to Submit** | Typically 3 working days |

#### **How PRF is Pre-Filled**

| PRF Field | Source (from Your Application) | Example |
|-----------|-------------------------------|---------|
| Date | Today's date | 15 May 2025 |
| College | Your profile | College of Engineering & IT |
| Requester Name | Your name | Dr. Fatima Al-Mansouri |
| Purpose | Auto-generated | "Conference Registration – IEEE AI Safety 2025" |
| Registration Fee | Section F | AED 3,500 |
| Flights | Section F | AED 2,100 |
| Accommodation | Section F (calculated) | AED 1,800 |
| Per Diems | Section F | AED 1,200 |
| **Total** | Sum of above | **AED 8,600** |

#### **Your PRF Review Steps**

| Step | Action | Details |
|------|--------|---------|
| 1️⃣ | Open PRF in CRS | Click "Review PRF" button on your application tile |
| 2️⃣ | Review auto-filled amounts | Each line item shown; check against your expectations |
| 3️⃣ | Edit amounts (if needed) | Click edit on any item, change amount, add explanation |
| 4️⃣ | Add quotations (if > AED 5,000) | Upload PDF/image of vendor quotes for large items |
| 5️⃣ | Review notes | Ensure any changes are explained in notes field |
| 6️⃣ | Confirm checklist | Check: "I have reviewed all amounts and they are accurate" |
| 7️⃣ | Submit PRF | Click "Submit PRF for Approval" → Enters PRF approval chain |

**If You Don't Submit Within 3 Days:**
- Reminder email sent
- PRF draft still editable
- Can submit anytime (but delays finance processing)

#### **PRF Approval Chain (6 Stages)**

| Stage | Approver | SLA | What They Check | Possible Outcomes |
|-------|----------|-----|-----------------|-------------------|
| **PRF-1** | College Dean | 1 day | Budget awareness | Approve → PRF-2 \| Reject → End \| Revise → Back to you |
| **PRF-2** | Director of Research | 1 day | Research fund availability | Approve → PRF-3 \| Reject → End |
| **PRF-3** | VP of Academic Affairs | 1 day | Policy compliance | Approve → PRF-4 \| Reject → End |
| **PRF-4** | Finance Department | 2 days | Budget availability, quotations | ✅ Approve \| 🔶 Partial approve (reduce amounts) \| ❌ Reject |
| **PRF-5** | UD President | 1 day | Strategic alignment | ✅ **FINAL APPROVE** (digital signature) \| ❌ **FINAL REJECT** |
| **PRF-6** | Procurement | – | Vendor engagement, booking | Notified; arranges travel |
| **PRF-7** | **YOU** | 1 day | Review bookings & confirm | ✅ Accept \| 🔄 Request mods \| 💬 Add comments |

#### **PRF Dashboard Status**

| Status | What It Means | What You See |
|--------|--------------|-------------|
| **Draft – Faculty Review** | Awaiting your review & submission | Edit/view pre-filled amounts, upload quotes, submit button |
| **Pending [Stage]** | Awaiting approver at PRF stage 1–5 | Current approver name, SLA status, elapsed time |
| **Approved & Booked** | Finance & President approved; Procurement completed bookings | Flight confirmations, hotel confirmations, instructions |
| **Requires Revision** | Finance reduced amounts due to budget constraints | Details of changes, option to accept or negotiate |
| **Rejected** | Rejected at any stage | Rejection reason, can discuss with Finance |

#### **If Finance Partially Approves**
- You receive email with adjusted amounts
- Original estimate: AED 8,600 → Reduced to: AED 7,500 (Finance note: "Budget constraints")
- You can: ✅ Accept reduction | 🤝 Negotiate (request Finance increase) | ❌ Withdraw
- If you negotiate, Finance responds within 2 days

#### **After President Approves & Procurement Books**
- You receive email: "Your conference travel has been booked"
- Includes flight confirmations, hotel address, conference registration #
- You must: ✅ **Accept** (confirms everything) | 🔄 **Request modifications** (e.g., different hotel room type) | 💬 **Add comments** (special requests)
- Once you accept: PRF marked "Approved & Finalized" → You're ready to travel

**Target Timeline:** Submit PRF Day 1 → Approved & Booked by Day 8–10

### 📋 PHASE 5: POST-CONFERENCE COMPLIANCE
**Duration:** 15 working days from conference end date | **5–10 working days per obligation**

#### **When Does This Activate?**
- Automatically triggers the **day after** your conference end date
- Banner appears in your dashboard: "Post-Conference Checklist – 5 tasks to complete"

#### **Your 5 Obligations**

| # | Obligation | Deadline | Evidence | Where to Submit |
|---|-----------|----------|----------|-----------------|
| **1** | Submit conference schedule with your name & paper | 5 working days | PDF or image of official conference program | CRS compliance uploader |
| **2** | Submit published paper copy to Library | 10 working days | PDF of full paper as published in proceedings | CRS compliance uploader |
| **3** | Provide proceedings copy to College RC & UD RC | 10 working days | Same PDF as #2 (or confirm "in-person delivery") | CRS compliance uploader |
| **4** | Submit actual expense receipts to Finance | 5 working days | Scanned receipts (PDF/image) – **only if advance was issued** | CRS compliance uploader |
| **5** | Complete conference feedback/report form | 10 working days | Free-text (500–1000 words) + optional supporting docs | In-app form editor |

#### **Timeline & Reminders**

| Days After Conference | What Happens |
|----------------------|--------------|
| **D+0 (day after end date)** | Checklist auto-activated; banner appears in dashboard |
| **D+3** | Reminder email if ANY obligation incomplete |
| **D+7** | Second reminder email + status update |
| **D+10–15** | Hard deadline approaching – Dean and Finance notified |
| **D+15** | If ANY obligation still incomplete → Faculty flagged as "Non-Compliant" |
| **D+30** | Final deadline; after this, serious compliance issue |

#### **How to Submit Each Obligation**

**Step-by-Step:**
1. Click "Post-Conference Checklist" banner in dashboard
2. Checklist view opens showing:
   - ⏳ Pending (not yet submitted)
   - ✅ Submitted (date & time stamp)
   - ⚠️ Overdue (past deadline)

3. For each obligation:
   - **Click obligation title** → Detailed instructions appear
   - **Upload file or enter text** as required
   - **Add notes** (optional) – e.g., "Delayed due to flight cancellation"
   - **Click "Submit"** → Timestamp recorded

4. **Once all 5 submitted:**
   - Status changes to ✅ "Compliance Complete"
   - You receive email: "Congratulations! Post-conference compliance complete."
   - Dean & Finance notified (for their records)
   - Application status → "Closed – Compliant"

#### **If You're Late**
- System flags as "Overdue" but allows submission up to D+30
- Include explanation note if delayed (e.g., "Delayed return due to flight reschedule")
- No penalty if reason is documented and reasonable
- If >30 days late with no explanation → May affect future conference eligibility

#### **Compliance Failure**
- If **ANY obligation incomplete** by D+15:
  - Email sent to you & your Dean
  - Message: "Post-conference obligations overdue. Failure to comply may affect eligibility."
  - Still allowed to submit late (up to D+30) with explanation
  - System tracks non-compliance history

## 🚨 COMMON ISSUES & QUICK FIXES

| Issue | Cause | Solution |
|-------|-------|----------|
| **"Cannot submit – Eligibility error"** | One of 4 eligibility questions answered "No" | Review Section D. If conference not SCOPUS-indexed, must choose different conference or wait for policy change. See Policy R 10.3. |
| **"Document upload failed"** | File too large (>10 MB) or unsupported format | Ensure file is PDF/image, max 10 MB. Compress if needed. Retry. |
| **"Application stuck – status hasn't changed"** | Approver delayed past SLA | System shows escalation flag. Click "Request Escalation" → VP notified. Typically resolved within 1 business day. |
| **"Returned for revision but confused about feedback"** | Approver comments unclear | Click "Request Clarification" → Opens Q&A thread with approver. Respond within 2 days. |
| **"Can't edit PRF after submission"** | PRF already entered approval chain | PRF locked once submitted. If Finance requests revision, they'll send it back to you. |
| **"Finance reduced my PRF budget"** | Budget constraints | You can ✅ Accept reduction, 🤝 Negotiate (request Finance increase), or ❌ Withdraw. Respond within 2 days. |
| **"Post-conference deadline passed – can I still submit?"** | Compliance overdue | Yes, you can submit up to Day 30 with explanation. Add note explaining delay (e.g., "Flight delay caused late return"). No penalty if reason is documented. |
| **"Forgot to submit compliance documents – flagged as non-compliant"** | Missed Day 15 deadline | Email Director & Dean explaining delay. Submit immediately with explanation note. May impact future conference eligibility; early submission of next application can help. |

## 💡 BEST PRACTICES & TIPS

### Before Submitting Application
1. **Have all documents ready** – Acceptance letter, paper, visa proof (if needed)
2. **Verify SCOPUS indexing** – Check conference website or Scopus database before completing form
3. **Get cost quotes** – Contact airlines, hotels for accurate estimates
4. **Confirm substitution** – Discuss with colleague before submitting
5. **Save as draft first** – Ensures no data loss if browser crashes
6. **Review Section D carefully** – All 4 questions must be "YES" or form cannot submit

### During Approval Workflow
1. **Monitor SLA** – Dashboard shows days remaining; prioritize if approaching deadline
2. **Respond quickly to info requests** – Don't let Q&A threads stall approval
3. **Check emails daily** – Approver comments may require timely response
4. **If returning for revision** – Provide clear explanations of changes; don't leave Dean guessing

### PRF Review
1. **Verify auto-filled amounts** – Compare against your actual quotes
2. **Attach quotations** – For items > AED 5,000, upload quotes to prevent Finance delays
3. **Submit PRF promptly** – Don't wait until deadline; Finance needs time to review

### Post-Conference Compliance
1. **Submit early** – Don't wait until deadline; gives Finance time to process reimbursements
2. **Organize receipts** – Scan all receipts before returning from conference
3. **Write detailed feedback** – Director of Research values insights on conference and research impact
4. **Confirm with Library** – Contact UD Library about proceedings submission format before return

## Summary: Your Journey in 5 Phases

```
Phase 1: Login (5 min)
   ↓
Phase 2: Submit Application (45 min to complete form + review)
   ↓
Phase 3: Track Approval (7–10 working days)
   ↓
Phase 4: Review & Submit PRF (3–5 days for you + 5–7 days for approval chain)
   ↓
Phase 5: Post-Conf Compliance (15 working days to complete 5 obligations)
   ↓
✅ DONE – Ready for next conference!
```

**Total Effort from Faculty:** ~2 hours (application form + PRF review + compliance tasks)  
**Total Cycle Time:** ~20–25 working days (from submission to travel-ready)

**Previous manual process:** 10–15 working days + 8+ hours of manual follow-up  
**CRS:** 8–10 working days + minimal follow-up needed

**Result:** Faster approvals, better visibility, automated reminders, and peace of mind! ✨
